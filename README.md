# M3 private processing

This private repository runs bounded M3 guitar-to-MIDI diagnostics on GitHub Actions. Source code comes from a full commit in Ajuntanaga/polyphonic-audio-to-midi. Recorded inputs live in the private corpus-20261108 release and are verified before use.

Dispatch M3 private processing with the source commit and task. Assignment traces compare a fresh OFF reference with an instrumented OFF replay. Corpus recovery produces new offline references; it does not authorize installation or live-use acceptance.

Reports are retained for 14 days and compressed evidence for 7 days. Collect important outputs into the project checkpoint before they expire. All new offloaded processing uses GitHub Actions. Legacy Kaggle jobs may only be collected.

No credentials or raw recordings belong in the git tree. The workflow uses its scoped GitHub token to read the private release. The installed scoreboard stays unchanged until a measured candidate passes its acceptance gates.
